# StudyMate — الموقع

## النشر على GitHub Pages

ينشر الملف `.github/workflows/deploy-website.yml` الموقع عند رفع تغييرات `website` إلى `main`، ويمكن تشغيله يدويًا من Actions. يجب اختيار **GitHub Actions** من إعدادات المستودع **Settings → Pages → Source**.

رابط النشر: https://mariam2020abd-hash.github.io/StudyMate/

يضبط `vite.config.ts` مسار ملفات البناء إلى `/StudyMate/`، بينما يبقى التشغيل المحلي على `/`. عند تغيير اسم المستودع أو استخدام نطاق مخصص يجب تحديث هذا المسار.

مشروع React + React DOM + Vite مستقل. لا يعتمد على أي ملفات من تطبيق الجوال.

من هذا المجلد، باستخدام Node.js 22.13 أو أحدث:

```sh
npm ci
npm run dev
```

- `npm run typecheck`: فحص TypeScript.
- `npm run build`: بناء الموقع داخل `dist`.
- `npm run preview`: معاينة البناء محليًا.

الصفحات داخل `src/pages`، والمكوّنات داخل `src/components`، وحالة لوحة الطالب داخل `src/hooks`. البيانات والأنواع والألوان تخص الموقع وحده.

تبدأ لوحة الطالب فارغة وتدعم إضافة المقررات والشابترات وتعديل أسمائها وحذفها وتتبع المراجعة. تُحفظ البيانات تلقائيًا في localStorage للمتصفح الحالي، وتبقى عند مغادرة اللوحة أو إعادة التحميل. لا تتزامن بين الأجهزة أو بين الموقع المحلي والموقع المنشور. حذف بيانات الموقع يمسحها، وقد يحذف المتصفح الخاص البيانات عند إغلاقه. تظهر رسالة عند تعذّر القراءة أو الحفظ، ولا تُستبدل البيانات التالفة تلقائيًا.

تشغيل اختبارات التخزين: `npm test`.

يمكن البحث باسم المقرر أو عنوان أي شابتر داخله، ثم البحث داخل المقرر وتصفية الشابترات إلى الكل أو للمراجعة أو تمت المراجعة. البحث يتجاهل التشكيل العربي واختلافات الألف وحالة الأحرف الإنجليزية. تظل إحصاءات التقدم محسوبة من جميع البيانات، وتستهدف عمليات التعديل والحذف الشابتر الصحيح حتى أثناء التصفية. يشمل `npm test` اختبارات البحث أيضًا.
