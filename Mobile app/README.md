# StudyMate — تطبيق الجوال

مشروع React Native + Expo مستقل لنظامي Android وiOS. لا يعتمد على أي ملفات من الموقع.

من هذا المجلد، باستخدام Node.js 22.13 أو أحدث:

```sh
npm ci
npm start
```

- `npm run android`: فتح التطبيق على جهاز Android أو محاكي جاهز.
- `npm run ios`: فتح محاكي iOS على macOS.
- `npm run typecheck`: فحص TypeScript.
- `npm run export`: تصدير حزم JavaScript/Hermes للمنصتين داخل `dist`، وليس APK أو IPA.

نقطة الدخول `index.ts`، والتنقل داخل `App.tsx`، والشاشات داخل `src/screens`. الحساب والمقررات والشابترات والمراجعة ورفع PDF تتصل الآن بخادم StudyMate نفسه المستخدم في الموقع. تحفظ الجلسة في SecureStore؛ وتبقى بيانات الدراسة في الخادم وتحتاج اتصالًا.

اضبط `EXPO_PUBLIC_API_URL` قبل تشغيل Expo. يتضمن `.env.example` عنوان التطوير الافتراضي. لمحاكي Android المتصل بالحاسوب الذي يشغّل الخادم، يمكن استخدام `adb reverse tcp:5287 tcp:5287` ثم `http://localhost:5287`. على جهاز حقيقي، يلزم عنوان خادم يمكن الوصول إليه من الجهاز وتكوين الاستضافة المناسب؛ `localhost` يشير إلى الجهاز نفسه. نسخة الإنتاج تتطلب HTTPS.

تحقق من البريد أو استعد كلمة المرور عبر رابط الرسالة، ثم عُد لتسجيل الدخول في التطبيق. في بيئة تطوير الخادم، الرسائل ملفات محلية كما يوضح `backend/README.md`. لوحة المشرف متاحة على الويب.

اعتماديات الجوال تتبع Expo SDK 54. حفظ الجلسة يستخدم [Expo SecureStore](https://docs.expo.dev/versions/v54.0.0/sdk/securestore/)، ورفع PDF يستخدم [Expo FileSystem وexpo/fetch](https://docs.expo.dev/versions/v54.0.0/sdk/filesystem/). تُحذف نسخة الملف المؤقتة التي أنشأها منتقي الملفات بعد محاولة الرفع، دون حذف الملف الأصلي.

التنفيذ مستمر: واجهات التوليد والاختبارات والأهداف وحاسبة المعدل في الجوال، واختبارات التشغيل الفعلية على Android وiOS، لم تكتمل بعد. تصدير الحزم أو نجاح TypeScript لا يثبت قبول التطبيق على جهاز.
